# Tide & Torque site

Public homepage, privacy policy and terms of use for the Tide & Torque channel and
its publishing tool (needed for the Google OAuth consent screen and the YouTube
API Services audit). Plain HTML, no scripts, no cookies, no personal data.

Published with GitHub Pages from the `main` branch root:

- Home: `index.html`
- Privacy policy: `privacy.html`
- Terms of use: `terms.html`
